# User Manual & Researcher Guide

## 1. Getting Started
Access the web portal at [http://localhost:5173](http://localhost:5173) in your browser.

## 2. Running a Scientific Query
1. Click **Concept Explorer**.
2. Type your question or scientific concept in English, Tamil, or Tanglish (e.g., `Astrophysics`, `விண்வெளி இயற்பியல்`, `vinveli iyarpiyal`).
3. Click **Run Multi-D Analysis**.
4. Inspect the **3-Score Panel**:
   - **Retrieval Relevance (%)**: Surface vector + lexical match.
   - **Evidence Strength**: Source support classification (`HIGH`, `MEDIUM`, `LOW`, `NONE`).
   - **Interpretation Confidence (%)**: Classification confidence score.

## 3. Exploring Evidence & Exporting Reports
- Open **Evidence Explorer** to view individual verses, semantic scores, and expert review statuses.
- Open **Research Workspace** to export reports in **JSON**, **CSV**, or **TXT Summary** formats.
